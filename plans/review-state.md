## 变更触发规则

| 发生变化 | 必须重新检查 |
|---|---|
| 实际出生日期/孕周/出生身长体重 | 0-12月营养、健康、运动、学校时间线、预算 |
| 身高体重、生长曲线、过敏、疾病、睡眠或喂养 | nutrition-agent、child-health-agent、physical-development-agent、发展仪表盘 |
| 现居地、落户、房产、园校目标或实际入学区 | family-policy-agent、0-3总体计划、预算 |
| 用户提供官方政策/招生/医院材料或链接 | 对应报告重新核对来源、有效日期和建议 |
| 家庭预算、照护者或工作安排 | education-resource-agent、预算、发展仪表盘 |
| 家长提供新的教育方法、课程或学习工具 | education-resource-agent 进行理论/证据审查；按年龄判断立即采用、以后留档或不建议采用 |
| 家长提供竞赛、考级或证书清单 | education-resource-agent 核验教育部当前名单/体育规程、主办资质、收费、评审、隐私和升学宣传；无完整链接不认定权威性 |
| 家长提供任何育儿观点、方法、数字或清单 | claim-review-agent 先归纳/拆主张，再转领域 Agent；结果登记到 evidence-review-register 和相应报告 |
| 家长提供运动/感统/前庭训练动作 | physical-development-agent 审查目标能力、适龄性、剂量与安全边界；涉及功能障碍转 child-health-agent/线下康复评估 |
