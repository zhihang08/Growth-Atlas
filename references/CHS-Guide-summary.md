## 证据优先级

本指南是本项目0-3岁健康养育照护的中国官方核心基线，优先于自媒体、商业课程、普通专家经验及未经核验的单项研究。

若发生冲突，按以下顺序处理：

1. 孩子的个体临床医嘱和急症处置要求。
2. 更新的国家法律、国家卫生健康主管部门现行规范、国家免疫规划或药品说明书。
3. 本指南。
4. 其他专业指南、系统综述和高质量研究。
5. 专家经验、教育流派、自媒体和商业宣传。

每次冲突必须记录来源日期和采用理由。本指南附件中的预警征象仅提示发育偏异可能，不用于家庭诊断。

官方身份不意味着文件内每个医学机制或治疗性表述自动等同最高等级临床证据。对于推拿“增强体质”、疾病治疗、补充剂剂量、户外暴露方式等具体问题，仍需结合更新专业指南、产品说明和孩子的临床医嘱；本摘要不将其扩写为治疗承诺。

## 八项基本理念

1. 重视体格、运动、认知、语言、情感和社会适应的全面发展。
2. 遵循生长发育规律、尊重个体差异，不盲目攀比、避免揠苗助长。
3. 观察表情、声音、动作和情绪信号，及时给予恰当、积极回应。
4. 在安全前提下提供自由玩耍和探索，培养自主、自理和自我调节，不包办代替。
5. 注重亲子陪伴、交流和玩耍，提倡父亲参与。
6. 把早期学习融入日常养育，通过模仿、重复和尝试发展能力。
7. 建立温馨和睦、安全有趣的家庭环境，提供适龄玩具、图书和生活用品。
8. 养育人持续学习并关注自身身心健康，及时缓解养育焦虑。

## 官方儿童健康管理节点

积极参加国家基本公共卫生服务0-6岁儿童健康管理：

- 出院后1周内
- 满月
- 3月龄
- 6月龄
- 8月龄
- 12月龄
- 18月龄
- 24月龄
- 30月龄
- 36月龄

每次关注体重、身长/身高、生长速度、心理行为发育和社会适应。体重或身长/身高低于第3百分位、高于第97百分位，或生长速度平缓、下降、突增时，应就诊评估；单次百分位不是家庭诊断。

## 心理行为发育问题预警征象

> 适用于0-6岁。相应年龄出现任意一条，仅提示发育偏异的可能，需要进一步专业评估。

| 年龄 | 预警征象 |
|---|---|
| 3月龄 | 对很大声音没有反应；逗引时不发音或不会微笑；不注视人脸/不追视移动人或物；俯卧不会抬头 |
| 6月龄 | 发音少/不会笑出声；不会伸手抓物；紧握拳松不开；不能扶坐 |
| 8月龄 | 听到声音无应答；不会区分生人和熟人；双手间不会传递玩具；不会独坐 |
| 12月龄 | 呼唤名字无反应；不会模仿“再见/欢迎”；不会拇食指对捏小物；不会扶物站立 |
| 18月龄 | 不会有意识叫爸爸/妈妈；不会按要求指人或物；与人无目光交流；不会独走 |
| 24月龄 | 不会说3个物品名称；不会按吩咐做简单事情；不会用勺吃饭；不会扶栏上楼梯/台阶 |
| 30月龄 | 不会说2-3字短语；兴趣单一刻板；不会示意大小便；不会跑 |
| 36月龄 | 不会说自己的名字；不会假想游戏；不会模仿画圆；不会双脚跳 |
| 4岁 | 不会说带形容词句子；不能等待/轮流；不会独立穿衣；不会单脚站立 |
| 5岁 | 不能简单叙说事情经过；不知道自己的性别；不会用筷子吃饭；不会单脚跳 |
| 6岁 | 不会表达感受/想法；不会角色扮演集体游戏；不会画方形；不会奔跑 |

## 眼、耳与口腔保健

### 眼保健

- 定期接受眼病筛查、视力与远视储备监测。
- 保证睡眠、均衡膳食和户外活动，减少持续近距离用眼。
- 2岁以内不建议观看或使用电子屏幕。
- 2岁以上每天累计不超过1小时，每次不超过20分钟。
- 不能追视/反应差、凑近/眯眼/斜眼/歪头看、瞳孔区发白、畏光流泪、眼红或脓性分泌物时及时就诊。

### 听力保健

- 接受耳及听力保健服务，观察声音反应和语言发育。
- 远离强声/持续噪声，不让婴幼儿使用耳机；不自行清洁外耳道。
- 耳周异常、分泌物/异味、反复抓耳、耳痛、声音反应迟钝、语言迟缓、常歪头或呼唤无回应时就诊。

### 口腔保健

- 第一颗乳牙萌出即开始清洁，按月龄选纱布、指套牙刷或儿童牙刷。
- 指南建议儿童含氟牙膏，米粒大小；具体产品和方法可在儿保/口腔检查时确认。
- 第一颗乳牙萌出至12月龄之间完成首次口腔检查和龋风险评估，之后每3-6个月检查。
- 避免餐间含糖饮食、食物嚼碎后喂、与孩子共用餐具。

## 营养与辅食

### 母乳和微量营养素

- 提倡早接触、早吸吮、早开奶；0-6个月纯母乳，不另加水和食物；按需哺乳，每日8-10次以上。
- 足月儿生后数日内在医生指导下每日维生素D 400 IU。
- 纯母乳/母乳为主足月儿4-6月龄可按需要适当补铁；早产/低出生体重儿补充必须遵医嘱。

### 6-24月龄辅食表

| 月龄 | 每日频次 | 每餐平均量 | 质地 |
|---|---|---|---|
| 刚满6月 | 继续母乳；泥糊状从1次逐步到2次 | 从尝试到2-3小勺 | 稠粥、肉泥、菜泥 |
| 6-9月龄 | 继续母乳；半固体逐步到1-2次 | 2-3勺逐渐到1/2碗（250ml碗） | 稠粥、糊、捣烂/煮烂家庭食物 |
| 9-12月龄 | 半固体2-3次 + 继续母乳 | 约1/2碗 | 细切家庭食物、手指/条状食物 |
| 12-24月龄 | 3次家庭餐 + 2次加餐 + 继续母乳 | 3/4碗至1碗 | 软烂家庭食物 |

食物覆盖7类：谷薯/主食、动物性食物、蛋、奶及奶制品、豆类及坚果制品、富含维生素A蔬果、其他蔬果。指南提出每日不少于4类，并至少含动物性食物、蔬菜和谷薯类；刚开始时仍遵循一次一种、少量开始、新食物适应2-3天。

合理制作：新鲜清洁、蒸煮炖煨；去除硬皮、骨、刺、核；豆类/坚果充分磨碎；1岁内不加盐糖/调味品，1岁后少盐少糖；避免腌制、卤制、烧烤、重油甜腻和辛辣。

### 饮食行为

- 1岁后逐步独立进食，家庭共同进餐；引导而不强迫，回应饥饱信号。
- 不以食物奖励或惩罚。
- 进餐不看电视/手机；每餐约20分钟，最长不宜超过30分钟。

## 亲子交流与玩耍分龄表

| 月龄 | 交流 | 玩耍/运动 |
|---|---|---|
| 0-1月 | 注视眼睛、温柔说话；喂养照护时让孩子看脸、听声音 | 看、听、接触照护者，自由活动四肢；抚摸、拥抱、肌肤接触 |
| 1-3月 | 喂奶/清醒时微笑、模仿声音、轮流交流 | 自由活动四肢；俯卧抬头；慢移彩色玩具供看/触摸 |
| 3-6月 | 经常说话、逗笑，模仿声音、表情和动作 | 俯卧抬头、帮助翻身、伸手够取/抓握不同质地玩具 |
| 6-9月 | 回应声音和兴趣；叫名字观察反应；躲猫猫；描述看到的人物 | 练习坐、翻滚；抓握、传递、敲打安全家庭物品 |
| 9-12月 | 认识物品、人和身体部位；说话、唱歌、配合拍手/挥手 | 鼓励爬行、站立和扶走；拇食指捏取；藏找游戏 |
| 12-18月 | 问简单问题并等待；用简单指令；鼓励称呼和看图说名称 | 独走、蹲起、涂画、套叠/堆叠、容器装取 |
| 18-24月 | 多说话、提问并等待；清晰回应；结合自然/图书交谈 | 户外；扶支撑上下台阶；扔/踢球；翻书、拧瓶盖；模仿游戏 |
| 24-36月 | 看图画书、讲故事、儿歌、讨论；教姓名/性别/形状/颜色/用途 | 单脚站、双脚跳、踢球；洗手、吃饭、扣扣子、穿鞋；同伴游戏 |

## 日常活动、睡眠与家庭环境

- 幼儿每天身体活动至少3小时，其中户外至少2小时；雾霾、高温等特殊天气酌减。
- 避免婴幼儿久坐超过1小时。
- 婴儿每日总睡眠12-17小时，幼儿10-14小时，夜间8小时以上；识别睡眠信号并建立规律作息。
- 设置固定、安全、有趣的活动区；提供适龄玩具、图书和生活用品。

## 伤害预防

- 看护时不同时使用手机或从事非必要活动；多人在场明确一名主要看护人。
- 水边、高处、动物旁保持伸手可及；不让未成年人单独看护婴幼儿。
- 清除小件、尖锐物、破损玩具、不安全电器、药物和化学品；隔离楼梯、厨房、水体等危险。
- 使用安全座椅、家具防护角、窗锁等合格适龄产品。
- 养育人应学习婴幼儿心肺复苏、气道异物处置和基础止血/烧烫伤处置。

## 危重症立即就诊信号

- 精神状态明显变差，进食量明显减少，不能喝水/吃奶。
- 抽搐或囟门凸起；频繁呕吐。
- 呼吸加快：小于2月龄每分钟超过60次；2-12月龄超过50次；2-3岁超过40次。
- 鼻翼扇动、胸凹陷、呼吸暂停伴发绀。
- 水样腹泻持续2-3天、血便、尿明显减少/无尿；眼窝/囟门凹陷、皮肤弹性差、哭时泪少。
- 脐部脓性分泌物多、脐周红肿；新生儿手掌/足底严重黄染、皮肤脓疱。
- 眼或耳部脓性分泌物。

## 与现有计划的冲突修正清单

1. 儿保节点必须补充“出院后1周内、满月、30月龄”。
2. 心理/语言预警应采用附件2分龄表，不使用“12月龄仍无社会性微笑”这类错误阈值。
3. 辅食新食物适应期采用2-3天；不把“先蛋黄、9月后蛋白”设为强制时间线。
4. 1岁后独立进食、无屏幕进餐、每餐20分钟左右/最长30分钟应写入执行计划。
5. 第一颗乳牙萌出即清洁，并在萌牙至12月龄完成首次口腔检查。
6. 2岁内不建议屏幕；2岁以上累计不超过1小时/日、每次不超过20分钟，应进入执行计划。
7. 幼儿活动至少3小时/日、户外至少2小时/日；特殊天气调整。
8. 预警征象只提示进一步评估，不作为家庭诊断。
